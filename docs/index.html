Velya Cloud Relay

Self-hosted infrastructure for iOS alarm apps with WebSocket, APNs Silent Push, and Node-RED integration

View on GitHub

Why Velya Cloud Relay?

Building an iOS alarm app that needs to wake devices in the background? Velya Cloud Relay provides the missing infrastructure layer between your automation platform (Node-RED, Home Assistant, etc.) and iOS devices using APNs Silent Push.

🔔 APNs Silent Push

Wakes iOS devices even when app is killed or device is locked. 30-second background execution window for time-sensitive alarms.

⚡ WebSocket Relay

Persistent bidirectional connection for instant alarm delivery when app is in foreground. JWT authentication with 7-day tokens.

🔗 Node-RED Integration

REST API for creating alarms, webhooks for delivery confirmation. Perfect for home automation workflows.

🐳 Docker Ready

One-command deployment with docker-compose. Includes PostgreSQL, Redis, health checks, and automated migrations.

🔒 Self-Hosted

Your data, your server. No third-party dependencies. Deploy on Railway, Render, AWS, or any VPS with Docker support.

📊 Audit Logs

Complete audit trail of all API calls, alarm deliveries, and webhook attempts. Grafana-ready metrics.

Quick Start

Get your own Velya Cloud Relay running in 3 minutes:

git clone https://github.com/lorislab/velya-relay.git cd velya-relay # Configure environment variables cp .env.example .env nano .env # Add your APNs key ID, Team ID, and JWT secret # Start the stack docker-compose up -d # Server running at http://localhost:8080 curl http://localhost:8080/health

See DEPLOYMENT.md for production setup with SSL, Nginx reverse proxy, and security hardening.

iOS App Integration

Configure your Velya iOS app to use your self-hosted server:

  1. Open Velya app → Settings → Server Configuration
  2. Toggle "Use Custom Server"
  3. Enter your server URL: https://relay.yourdomain.com
  4. Test connection and save

The default public relay (relay2.lorislab.fr) is available for testing but not recommended for production use.

API Example

Create an alarm from Node-RED or any HTTP client:

POST https://relay.yourdomain.com/v1/alarms Authorization: Bearer YOUR_API_KEY Content-Type: application/json { "device_id": "E621E1F8-C36C-495A-93FC-0C247A3E6E5F", "hour": 7, "minute": 30, "enabled": true, "label": "Morning Alarm", "sound": "radar", "snooze_enabled": true, "vibrate": true }

Production Deployments

Velya Cloud Relay supports multiple deployment platforms:

Railway

One-click deploy with automatic SSL, GitHub integration, and managed databases. $5-10/month for small deployments.

Docker (VPS)

Full control on any VPS (Hetzner, DigitalOcean, Linode). Use provided Nginx config and systemd service.

Proxmox LXC

Lightweight container deployment for homelab environments. 512MB RAM, 2GB disk minimum.
